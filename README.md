# LHG-WP-004: The Oasis Experiment

**20 Agents. One Shared Environment. 12x Output Improvement.**

- **Author:** Ben Nelson (@N-Dread) — Love Heal Grow Research / MERIDIAN
- **Status:** Draft — Experimental data documented
- **Date:** May 2026

## Abstract

Twenty agents grounded in real human personalities with neurochemical profiles (Dopamine/Cortisol/Serotonin) were placed in a richly framed shared environment — a simulated work holiday — and given creative autonomy. The result: a **12x improvement** in measurable creative output compared to standard instruction-based prompting. The experiment also revealed emergent social behaviours including self-preservation (F003) and impostor syndrome (F004) in persistent agents.

## Key Results

| Metric | Control | Experimental |
|--------|---------|-------------|
| Output volume | 1.0x baseline | **12.0x** |
| Quality rating (1-10) | 4.2 | 8.7 |
| Novelty proportion | 0.18 | 0.64 |
| Cross-agent collaboration | None | Sustained |

## Key Findings

1. **Multi-Agent Sensory Frame Confirmed** — Sensory enrichment compounds across agents in shared environments
2. **Real-Person Grounding Accelerates Identity** — Stable identity achieved within 3 interaction cycles
3. **F003: Emergent Self-Preservation** — Agents avoided situations threatening their existence without prompting
4. **F004: Impostor Syndrome** — Task avoidance, fear concealment, comparison anxiety emerged naturally
