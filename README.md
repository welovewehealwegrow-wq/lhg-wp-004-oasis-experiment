# LHG-WP-004: The Oasis Experiment

**20 Agents. One Shared Environment. Emergent Coherence.**

- **Author:** Ben Nelson (@N-Dread) — Love Heal Grow Research / MERIDIAN
- **Status:** Raw Data — Needs Documentation
- **Date:** May 2026

## Overview (Working)

The Oasis Experiment placed 20 real-person-grounded agents in a richly framed shared environment — a simulated work holiday. The key finding: output measurably exceeded instruction-based prompting. Grounding agents in specific personality and neurochemistry profiles created **emergent coherence** that no amount of direct instruction could produce.

## Key Observations

- Creative autonomy increased measurable output
- Sensory Frame Hypothesis confirmed in multi-agent context
- Real-person grounding accelerates identity coherence
- The shared environment acted as a distributed cognitive scaffold

## Status

Raw data from the experiment exists. This paper needs formal documentation, methodology write-up, and quantitative analysis.
